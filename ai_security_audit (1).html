🧠 AI-Detected Hidden Vulnerabilities

🔴 Issue 1: Insecure S3 Logging Configuration

  • Severity: 🔴 Critical
  • Category: Infrastructure (IaC)
  • Location: ZNF/main.tf
  • Description: Logging is configured on the same S3 bucket used for storing data. This can lead to recursive logging, data integrity concerns, or accidental exposure if bucket policies change.
  • Why Tools Missed It: Static scanners assume logging in–bucket is acceptable; they do not enforce AWS best practices regarding bucket isolation.
  • Suggested Fix:
hcl// Before (vulnerable)
resource "aws_s3_bucket_logging" "student_bucket_logging" {
  bucket        = aws_s3_bucket.student_data_bucket.id
  target_bucket = aws_s3_bucket.student_data_bucket.id
  target_prefix = "logs/"
}

// After (secure: use separate logging bucket)
resource "aws_s3_bucket" "logging_bucket" {
  bucket = "ims-christ-university-logs"
  acl    = "log-delivery-write"
}

resource "aws_s3_bucket_logging" "student_bucket_logging" {
  bucket        = aws_s3_bucket.student_data_bucket.id
  target_bucket = aws_s3_bucket.logging_bucket.id
  target_prefix = "logs/"
}
  • Tool Upgrade: Checkov rules for cross-resource dependencies.

🔴 Issue 2: Missing Content-Security-Policy in Frontend

  • Severity: 🟠 High
  • Category: Frontend Security
  • Location: ZNF/index.html
  • Description: No Content-Security-Policy (CSP) header is defined, increasing risk of XSS and injection attacks.
  • Why Tools Missed It: Basic HTML analysis may not flag missing security headers without runtime context.
  • Suggested Fix:
html<!-- Before (vulnerable) -->
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>ZNF Repair & Services</title>
  <!-- Styles and other meta tags -->
</head>

<!-- After (secure) -->
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'">
  <title>ZNF Repair & Services</title>
  <!-- Styles and other meta tags -->
</head>
  • Tool Upgrade: Integrate security header checks into CSP scanner.
